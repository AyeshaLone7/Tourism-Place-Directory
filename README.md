# DiscoverPK 
### Discover Pakistan, One Destination at a Time

## Project Overview

**DiscoverPK** is a web-based tourism platform developed using Laravel to help users explore tourist destinations across Pakistan. The website provides destination search, detailed place information, Google Maps integration, user authentication, and a personalized favorites feature.

The main objective of this project is to make discovering tourist destinations in Pakistan easier and more convenient through a user-friendly digital platform.

## Key Features

### 1. Explore Tourist Destinations
- Browse tourist destinations across Pakistan.
- View destination details, including names, locations, and descriptions.
- Search for places to find relevant destinations.

### 2. Google Maps Integration
- Display destination locations using Google Maps.
- Help users identify the geographical location of tourist places.
- Make it easier for users to visualize destinations and plan their visits.

### 3. User Authentication
- User registration and login.
- Secure password storage using hashing.
- Session-based authentication.
- Secure logout functionality.

### 4. My Favorites
- Save preferred tourist destinations.
- View saved places on a dedicated favorites page.
- Remove destinations from the favorites list.
- Maintain a separate favorites list for each authenticated user.

### 5. Website Navigation
- Home page
- About page
- Contact page
- Explore Places page
- Login and Sign Up pages
- My Favorites page

### 6. User Interface
- Clean and user-friendly design.
- Responsive styling using Tailwind CSS.
- Consistent color theme and navigation.
- Navigation options based on the user's authentication status.

## Technologies Used

- **Backend:** PHP and Laravel
- **Frontend:** HTML, CSS, Blade Templates, Tailwind CSS
- **Database:** MySQL
- **Mapping:** Google Maps integration
- **Version Control:** Git and GitHub

## Project Structure

The project follows the Laravel MVC (Model-View-Controller) architecture.

- **Models:** Manage application data and database relationships.
- **Views:** Display website pages using Blade templates.
- **Controllers:** Handle authentication, destination-related operations, and favorites.
- **Routes:** Define website URLs and connect them to the appropriate controllers.
- **Migrations:** Manage database table structures.

## Installation and Setup

1. Clone the project repository.
2. Navigate to the project directory.
3. Install the required PHP dependencies using Composer.
4. Configure the local environment and database.
5. Run the database migrations.
6. Start the Laravel development server.
7. Open the local application URL in a web browser.

Refer to the project's environment configuration and dependency requirements when setting up the application locally.
